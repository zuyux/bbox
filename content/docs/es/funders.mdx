---
title: Guía para financiadores
description: Evalúa proyectos e hitos, comprende la evidencia y toma decisiones de financiación mejor informadas.
---

BBOX ayuda a comparar afirmaciones con evidencia pública. No ofrece asesoría financiera ni garantiza entrega, reembolso, seguridad o valor futuro.

## Empieza por el registro

Comprueba que sitio, repositorio, perfil y canales de versiones pertenecen al mismo proyecto. Busca mantenimiento activo, atención a incidencias, versiones etiquetadas, licencia clara y documentación útil.

Las calificaciones y la verificación son entradas, no conclusiones.

## Evalúa el trabajo propuesto

Identifica para cada hito:

1. **Resultado:** qué capacidad o artefacto observable existirá.
2. **Aceptación:** qué condiciones definen que está completo.
3. **Evidencia:** qué versión, código, prueba o informe se revisará.
4. **Alcance:** qué queda excluido.
5. **Dependencias:** qué factores externos pueden bloquearlo.
6. **Mecánica de fondos:** quién los custodia y cómo se autoriza el pago.

Si dos revisores razonables pueden interpretar la finalización de forma distinta, el hito necesita más detalle.

## Relaciona evidencia y afirmación

Una captura demuestra progreso visual, no calidad del código. Un pull request demuestra cambios, no un producto publicado. Un hash identifica un artefacto, pero no prueba equivalencia con el código fuente.

## Entiende los límites

BAR muestra un historial de metadatos autorizado por el editor, pero no custodia fondos, audita código ni ejecuta hitos. BBOX presenta contexto, pero la custodia y las condiciones de pago deben evaluarse por separado.

## Lista de revisión

- [ ] Identidad y enlaces coherentes
- [ ] Repositorio y licencia accesibles
- [ ] Resultado observable
- [ ] Criterios de aceptación inequívocos
- [ ] Evidencia adecuada
- [ ] Riesgos y dependencias declarados
- [ ] Custodia y pago comprendidos
- [ ] Ninguna insignia se trata como garantía
