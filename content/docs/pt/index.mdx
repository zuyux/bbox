---
title: O que é o BBOX?
description: Entenda como o BBOX ajuda a descobrir, avaliar e apoiar software de código aberto.
---

BBOX é uma camada de coordenação de código aberto para descoberta, verificação e financiamento de software. Seu foco inicial é o ecossistema Bitcoin: carteiras, ferramentas Lightning e Nostr, software de privacidade, infraestrutura para desenvolvedores, camadas Bitcoin e outros bens públicos.

Lojas tradicionais respondem a uma pergunta limitada: **o que posso instalar?** O BBOX procura responder questões mais amplas:

- Quem publica e mantém o projeto?
- Onde está o código-fonte?
- Qual versão, plataforma e licença o registro descreve?
- Que evidências sustentam verificação e reputação?
- Que trabalho a equipe planeja e como financiá-lo?
- Como o registro mudou ao longo do tempo?

## As três partes do BBOX

### 1. Um índice de software legível

Cada página reúne descrição, categoria, plataformas, repositório, site, publicador, mídia, avaliações e estado de verificação. Os registros podem ser pesquisados e comparados sem ocultar as fontes originais.

### 2. Uma superfície de coordenação e financiamento

Publicadores podem descrever trabalho planejado como marcos observáveis. Financiadores podem analisar o resultado esperado e suas evidências em vez de avaliar apenas um nome e endereço de pagamento.

### 3. Uma camada soberana de metadados

O [Bitcoin App Registry (BAR)](/pt/documentation/bar-protocol) define um formato mínimo controlado pelo publicador e ancorado por inscrições Taproot. Indexadores independentes podem reconstruir o estado atual e seu histórico.

## Como as partes se conectam

```text
Publicador
  ├─ publica dados e mídia → BBOX / IPFS
  ├─ ancora mudanças canônicas → BAR no Bitcoin L1
  └─ propõe trabalho e evidência → marcos

Usuários e financiadores
  ├─ descobrem projetos → índice BBOX
  ├─ analisam código, identidade, histórico e avaliações
  └─ decidem de forma independente se instalam ou apoiam
```

BBOX pode apresentar dados de serviços web, IPFS, comunidade e blockchain. BAR é mais específico: estabelece uma cadeia canônica de metadados controlada pelo publicador. Nenhuma camada prova por si só que o software é seguro.

## O que significa “verificado”

Verificação é um sinal adicional, não uma garantia. Analise propriedade do repositório, assinaturas, builds reproduzíveis, auditorias, permissões e manutenção recente. Consulte [Confiança e verificação](/pt/documentation/trust-and-verification).
